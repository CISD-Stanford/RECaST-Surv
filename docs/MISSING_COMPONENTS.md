# Additional materials

The optional R-MAP model and ALS synthetic input are supplied separately. Their filenames, identity requirements, and entry points are listed in [optional inputs and dependencies](../external/README.md).

The archive provides code, configurations, and documentation for new analyses. It does not include the simulation result banks, saved chains, or all inputs needed to recreate every manuscript table. Use the [scenario guide](SCENARIO_COVERAGE.csv) and [ALS guide](../modules/ALS/README.md) to select a documented workflow. License information is in [LICENSE_STATUS.md](LICENSE_STATUS.md).
